&#x20;Hotel Management Network



&#x20;A Small, Secure, and Organized Hotel Network Designed in Cisco Packet Tracer



This project is a simulated network for a hotel environment, designed using Cisco Packet Tracer.

The network connects different hotel departments and provides a structured setup for communication, resource sharing, and basic network management.



&#x20;📌 Project Overview



The network was designed to represent the IT infrastructure of a small hotel. Different departments are connected through switches and routers, allowing staff to communicate and access shared network resources.



The main focus of the project is to build a network that is:



\* Simple to manage

\* Secure and organized

\* Easy to expand

\* Suitable for different hotel departments



🏢 Hotel Departments



The network includes several departments such as:



\* Reception

\* Management

\* Accounting

\* Housekeeping

\* IT Department

\* Guest Services



Each department has its own connected devices and network access.
